# 네이티브 카드 UI · 2026-11-03 중앙 정렬·등장 효과

O의 680×440 카드 화면과 표시 루프를 개선한 전체 소스입니다.

- `Cleanner`의 게임 6종과 `Spoofer`의 안티치트 소개 6종을 분리합니다. 안티치트 소개는 정보 표시이며 식별자 변경·우회 기능을 수행하지 않습니다.
- 선택 카드의 색상을 넓게 움직이는 상단 빛·로고·탭 강조에 적용합니다. 두 탭은 중앙 카드의 좌우 끝에 맞춘 같은 폭이며, 아이콘과 글자 묶음을 각각 가운데 정렬합니다.
- 카드 하단의 별도 이름 띠는 제거합니다. 제목이 없던 네 표지는 이미지 안에 이름을 넣고 기존 제목이 있는 표지는 유지합니다. 클릭 정보 화면의 제목과 설명은 유지합니다.
- 처음 표시될 때 전체 UI가 중앙에서 부드럽게 펼쳐지고 나타납니다. 등장 효과는 한 번만 실행하며, 숨겨진 초기 준비 시간에 소모되지 않습니다. 효과 중 입력은 차단합니다.
- 드래그 추종·관성 정렬을 유지하며 중앙 카드가 커져도 카드 사이의 실제 빈 간격을 같게 맞춥니다. 클릭하면 미리 흐리게 만든 이미지 위의 반투명 정보 표시가 나타납니다.
- 창 모서리는 Windows DirectComposition의 부드러운 클립으로 합성합니다. 이진 GDI 영역으로 모서리를 잘라내는 경로를 제거합니다. Windows 10 이상의 DirectComposition/D3D11 경로를 사용합니다.
- 고정 16ms 메시지 타이머를 제거하고 모니터에 맞춘 Present와 정밀 프레임 시간을 사용합니다. 특정 주사율이나 모든 GPU에서의 성능을 보증하는 것은 아닙니다.

## START

`START`는 이제 로컬 알림 동작입니다. 잠시 로딩하는 동안 카드·탭·드래그·버튼을 비활성화하고 금지 커서를 표시합니다. 이후 체크 애니메이션과 준비 알림을 띄우며 화면을 유지합니다. 세션 종료나 서버 작업 성공을 뜻하지 않습니다. 기존 START의 A/B/O 조합 종료 요청 연결은 제거했습니다.

창을 직접 닫거나 실제 권한 만료·철회·무결성 오류가 발생했을 때의 정상 종료·정리 정책은 유지합니다.

## 아무 조작 없이 종료되는 현상

확인한 최근 실행은 마지막 서버 승인 기한 전에 클라이언트가 닫혔습니다. 그 기록만으로 단일 원인을 확정할 수 없습니다. 기존 작업자는 일시적인 갱신 통신 오류 한 번에도 즉시 종료했습니다. 새 버전은 명시적으로 분류된 연결 시간 초과(`CONNECT_TIMEOUT`)에 한해 현재 승인 기한 안에서 한 번 재시도합니다. 취소·철회·인증·무결성 오류를 재시도로 통과시키거나 승인 시간을 늘리지 않습니다.

갱신 실패와 화면 실행 오류를 구분하는 제한된 종료 진단을 추가합니다. 임의 예외 문자열·토큰·파일 경로를 서버 기록으로 전송하지 않습니다.

## 적용과 검증 범위

전체 소스를 새 폴더에 풀고 `Relay Server/tools/overlay/Prepare_ImGui.bat`로 최신 오브젝트를 생성·검사합니다. 성공 후 RAD Studio에서 `Cozy.Projects/Cozy.Overlay/Cozy.Overlay.dproj`를 Win64 Release로 **Rebuild**합니다. 최종 새 O로 기존 승인·명세·후보 등록·조합 검증·게시를 진행합니다. 기존 승인 자료를 변경된 실행 파일에 재사용하지 않습니다. Build-All BAT는 필수가 아닙니다.

그래픽 합성 경로의 API 계약이 바뀌므로 묶음에 포함된 최신 `tools/Cozy.Check-ApiSlots.bat`를 사용합니다. 서버 GitHub·Railway 배포만으로 PC의 기존 실행 파일이 교체되지는 않습니다. 키와 운영 등록 데이터는 초기화하지 않습니다.

실제 Dear ImGui 코어·입력·메모리·소스 계약 검사는 Windows/Delphi 빌드와 실제 GPU 실행을 대신하지 않습니다. 라이선스 없이 표시 경로를 확인하려면 `Cozy.Tests/Cozy.Overlay/Cozy.OverlayGraphicsProbe.dproj`를 Win64 Release로 Rebuild·실행할 수 있습니다.

공식 이미지 출처와 변환은 `Cozy.ImGui/Cozy.Assets/Cozy.Cards/Cozy.Cards.Provenance.md`를 참고하세요.
