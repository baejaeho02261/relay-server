GameConnect TLS 적용 안내 · FIX87 (TLS 동작 유지)

기본 운영
제공 Dockerfile: Node 22.14 이상, OpenSSL, 시스템 인증서.
HTTP 관리자 8080 / 네이티브 TLS TCP 3000 / 기존 외부 TCP 프록시 유지.
DATA_DIR=/data 등 영구 볼륨을 연결하고 단일 인스턴스(HA_ENABLED=0)로 실행합니다.
프로필에는 공개 접속지와 인증서 DER SHA-256 지문·TLS 이름이 포함됩니다. 비밀 키는 서버에만 둡니다.

새 설치
자동 인증서는 RSA 3072비트, 무작위 32자리 16진수.invalid DNS SAN/CN, 825일 유효기간입니다.
무작위 이름은 최초 생성 후 보존합니다. 실행/접속마다 이름이나 지문을 바꾸지 않습니다.
CONNECT_TLS_SERVER_NAME을 명시하면 그 이름을 사용합니다.
connect-tls/의 불변 세대 디렉터리와 connect-tls.sha256 포인터를 함께 보존하세요.
인증서·키·포인터 누락/손상/변경을 무시하고 재발급하여 신뢰하는 경로는 없습니다.

기존 FIX85 교체
서버 소스만 업데이트하면 기존 인증서와 지문은 유지됩니다.
game-connect.internal 또는 GameConnect TLS 표기를 없애려면 자동 인증서를 명시적으로 교체해야 합니다.
1. 서버를 완전히 중지합니다. 같은 DATA_DIR와 같은 포트 설정으로 명령을 실행해야 합니다.
2. DATA_DIR 전체를 안전한 서버 저장소에 백업합니다.
3. 예전 CONNECT_TLS_SERVER_NAME을 지정했다면 제거합니다. 지정된 이름은 무작위화하지 않습니다.
4. GameWeb에서 실행: npm run tls:rotate -- --offline
5. 출력되는 TLS_BACKUP_ID를 관리자 전용으로 보관합니다. 서버를 재시작하고 새 A를 발급합니다.
   기존 A의 인증서 지문은 자동 갱신되지 않으므로 새 인증서 서버에 연결할 수 없습니다.

교체는 실행 중인 서버 포트가 있으면 거부됩니다. 명령은 개인 키를 출력하지 않습니다.
기존 인증서는 DATA_DIR/connect-tls/backups 아래 보호된 복구 자료로 보존합니다.
새 인증서와 키를 완성한 뒤 포인터를 원자적으로 교체합니다.
중간 중단 상태는 시작 차단으로 처리하며 자동으로 다른 인증서를 신뢰하지 않습니다.
복구: npm run tls:restore -- --offline --backup <출력된 48자리 백업 ID>
복구도 서버 중지·같은 DATA_DIR·포트 환경에서만 실행합니다.
복구는 백업 인증서가 아직 유효해야 하며 그 지문에 맞는 A만 다시 연결할 수 있습니다.
개인 키 백업을 관리자 웹 공개 파일이나 소스 압축에 넣지 마세요.

외부 인증서
CONNECT_TLS_CERT_FILE과 CONNECT_TLS_KEY_FILE을 모두 지정합니다.
CONNECT_TLS_SERVER_NAME과 정확히 일치하는 DNS SAN, RSA 2048비트 이상 개인 키가 필요합니다.
인증서 유효기간·키 일치·기존 고정 지문을 검증합니다.
외부 인증서 구성은 자동 교체 도구가 거부하며, 운영자가 별도 보안 절차로 교체해야 합니다.
지문 변경 후에는 새 A 발급이 필요합니다. 기존 지문 검증을 끄지 마세요.

보호 범위
네이티브는 Schannel TLS 1.2 인증서 고정 검증을 사용하고 서버는 TLS 1.2/1.3을 수용합니다.
TLS 1.2는 ECDHE-RSA/AES-GCM만 허용합니다. 내부 RSA-OAEP-SHA256/AES-256-GCM도 유지합니다.
평문 TCP로 되돌아가기, TLS 1.0/1.1, 정적 RSA 키 교환, 변조 태그·재전송은 거부합니다.
TLS 1.2 SNI·인증서와 TCP IP·PORT·길이는 관측될 수 있습니다. 무작위 이름은 메타데이터 암호화가 아닙니다.
수신 PC 메모리의 정당하게 복호화된 데이터를 그 PC 관리자에게 영원히 숨기는 기능은 아닙니다.
관리자 웹은 기존 HTTPS 역방향 프록시를 사용하며 HTTP/TCP 포트를 서로 바꾸지 마세요.
