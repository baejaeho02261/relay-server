# O 다운로드 시간 초과 수정

2026-11-03 실행의 서버 로그에는 PREPARED 후 299.748초 동안 O 청크 요청 84회가 기록됐고, Finish·READY·CLAIMED 없이 부모가 중단했습니다. B의 300초 다운로드 제한과 일치하는 실패입니다. 이 기록은 O의 GPU 생성 실패나 실제 프로세스 잔류를 입증하지 않습니다.

## 변경

- 내장 카드·흐림 이미지의 저장 형식을 무손실 QOI로 바꿉니다. GPU 업로드 직전에 제한된 임시 버퍼에서 원래 RGBA8 픽셀로 복원합니다. 이미지 해상도·픽셀·레이아웃·애니메이션은 유지합니다. 이미지 데이터는 20,054,016바이트에서 7,011,543바이트로 줄었습니다. 이는 최종 Windows EXE 크기가 아니라 내장 이미지 데이터의 크기입니다.
- B가 다운로드 시간 초과와 다운로드 티켓 만료를 구분해 보고합니다. 서버는 서명된 B 진단의 두 고정 코드만 추가로 수락하며, 자유 텍스트·티켓·키·파일 경로는 받지 않습니다.
- 300초 다운로드 제한, 410초 인계 제한, 현재 부모 권한 확인과 전체 파일 해시는 유지합니다.
- 이전 O1324 대응의 classic bcc64 `-fdata-sections` 옵션을 유지합니다.

## 적용

1. 제공된 수정 파일을 최신 소스에 같은 경로로 덮어씁니다.
2. RAD Studio IDE에서 B `Cozy.Client.dproj`와 O `Cozy.Overlay.dproj`를 각각 Win64 Release로 Rebuild합니다. O 프로젝트의 사전 빌드가 C++ 오브젝트를 다시 만듭니다. 예전 `.o`를 복사하지 마세요.
3. 라이선스 사용 전 `Railway/Cozy.Tests/Cozy.Overlay/Cozy.OverlayGraphicsProbe.dproj`를 IDE에서 Win64 Release로 Rebuild하고 실행해 카드 표시와 PASS를 확인합니다. 이 검사는 서버 다운로드 성공까지 검증하지는 않습니다.
4. 새 B/O를 승인·후보 등록하고, 새 명세로 조합 검증 후 게시합니다. 기존 A 빌드 후보를 사용할 수 있지만, 실행용 A는 새 조합에서 다시 발급해야 합니다.
5. 이번 실패로 사용된 라이선스는 복구되지 않습니다. 테스트 PC의 기존 1회 사용 차단이 있으면 관리자에서 해제하고 새 라이선스와 새 발급 A를 사용합니다.

Windows RAD Studio 빌드와 실제 GPU·서버 연결 실행은 개발 환경에서 실행하지 못했습니다. 압축 복원 검증이나 서버 테스트 통과를 Windows 실행 성공으로 간주하지 않습니다.
