Game A / B / O 공부용 프로젝트

이 프로젝트는 공부용으로 제작되었으며, 실제 사용을 목적으로 하지 않습니다.

  • A/B 인증 흐름을 유지하면서 GameOverlay O 배포·일회용 인계·별도 세션을 추가했습니다.
  • Android 전용 소스·리소스와 의존성을 제거하고 과거 서버 데이터는 실행 기능 없이 보존합니다.
  • 웹 인증·세션·업로드·SSE 처리와 관련 회귀 검사를 보완했습니다.

서버/소스 테스트와 실제 Windows 컴파일·렌더링 검증은 다릅니다. 이 환경에는 Delphi 컴파일러가 없으며, 컴파일된 EXE를 포함하지 않습니다.
