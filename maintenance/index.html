빌드 및 배포 도구

GameWeb/tools에서 기능별 BAT를 실행합니다. Prepare_ImGui는 ImGui 오브젝트 준비, Create_Spec은 규격 작성, Create_Approval과 Check_Approval은 실행 파일 승인과 확인, Create_Release_Manifest와 Check_Release_Manifest는 배포 명세 생성과 확인을 담당합니다.

spec.json, deployment-policy.json, release-manifest.json과 승인 JSON은 BAT와 같은 tools 폴더에서 관리합니다. 정책은 관리자 화면에서 현재 정책을 내보내 사용합니다. 배포 명세는 승인 처리가 끝난 최종 A/B/O 파일로 생성합니다.

GameLauncher.dproj, GameConnect.dproj, GameOverlay.dproj를 RAD Studio에서 Release / Win64로 빌드합니다. Overlay는 Dear ImGui / D3D11입니다. Windows 네이티브 빌드 및 실행 여부를 포함한 검증 결과는 review.json에 기록합니다.

npm test는 GameWeb에서, python GameWeb/scripts/verify-source.py는 소스 루트에서 실행합니다. source-manifest.json은 파일 일치 확인용이며 발행자 서명을 대신하지 않습니다.
