# 네이티브 카드 UI · 2026-11-03

O의 680×440 카드 화면을 다듬은 전체 소스 배포입니다. 웹 관리자 및 서버의 인증·서명·기기·무결성 정책은 유지합니다.

- 6개 게임 표지, 중앙 카드 강조와 주변 카드의 어두운 비활성 표현.
- 포인터를 따라가는 드래그와 놓은 뒤 부드러운 정렬, 클릭·휠·키보드 전환.
- 카드 위 `Cleanner` / `Spoofer` 탭. 탭은 화면 선택용이며 청소·식별자 변경 기능을 새로 추가하지 않습니다.
- 넓어진 카드 영역, 줄인 창·카드·버튼 모서리, 움직이는 배경 빛.
- 정보 아이콘 제거, 더 큰 `START` 버튼, 흰색·보라색 기하 로고.

`START`의 기존 동작은 유지합니다. 버튼 로딩 후 인증된 현재 A/B/O 조합의 종료 요청을 수행하고, 서버 확인을 받은 경우에만 종료 알림을 표시합니다. 다른 사용자의 세션이나 Railway 서비스 전체를 종료하지 않습니다. 실패·권한 만료를 성공으로 표시하지 않습니다.

## 적용

전체 소스를 새 폴더에 풀고 RAD Studio에서 `Cozy.Projects/Cozy.Overlay/Cozy.Overlay.dproj`를 Win64 Release로 **Rebuild**합니다. 기존 빌드 준비 과정이 최신 네이티브 오브젝트를 생성·검사합니다. 새 O의 최종 바이트로 기존 승인·명세·후보 등록·조합 검증·게시 절차를 진행합니다. 기존 승인 자료를 변경된 실행 파일에 재사용하지 않습니다.

서버 GitHub·Railway 반영은 서버 배포이며, 기존 PC의 O 실행 파일이 자동으로 바뀌지는 않습니다. A/B의 업무 기능, 키와 등록 데이터는 이번 UI 변경으로 초기화하지 않습니다. API 슬롯 개수와 C/Pascal 함수 ABI는 유지합니다.

실제 Dear ImGui 코어와 입력 회귀 검사·DPI별 도형 출력을 확인하며, Linux의 CPU 출력 검사는 Windows/Delphi 컴파일이나 실제 GPU 표시 검사를 대신하지 않습니다. 라이선스 없이 로컬 그래픽 경로를 확인하려면 `Cozy.Tests/Cozy.Overlay/Cozy.OverlayGraphicsProbe.dproj`를 Win64 Release로 Rebuild·실행할 수 있습니다.

공식 게임 표지의 출처·변환 방식은 전체 소스의 `Cozy.ImGui/Cozy.Assets/Cozy.Cards/Cozy.Cards.Provenance.md`에 기록합니다.
