오류 화면을 직접 확인하고 보내세요

운영자가 발급한 10분짜리 일회용 링크입니다. 이 페이지는 사용자가 선택한 화면의 정지 이미지 한 장만 받습니다. 자동 촬영·반복 촬영·동영상·음성·키보드 입력 수집은 하지 않습니다.

촬영 직후 화면 공유를 종료합니다. 미리보기는 전송 버튼을 누르기 전까지 이 브라우저에만 있습니다. 전송한 이미지는 지정된 회원의 진단 자료로 운영자에게 제공됩니다. 24시간 후 열람이 만료되고 서버 정리 시 삭제됩니다. 서버 중단 중에는 실제 삭제가 늦어질 수 있습니다. 화면만으로 공격이나 변조를 확정하지 않습니다.

진단 링크를 확인하고 있습니다.

1. 보내려는 화면 선택

계정·대화·문서·비밀번호가 보이지 않는 프로그램 창을 권장합니다. 전체 화면을 선택하면 다른 앱의 내용도 포함될 수 있습니다.

지원하는 HTTPS 브라우저에서 화면 선택이 가능합니다. 지원하지 않으면 직접 만든 PNG를 선택하세요. 입력 PNG는 2 MiB 이하, 각 변 4096 픽셀 이하, 총 4,194,304 픽셀 이하입니다. 전송 이미지는 최대 1920 × 1080으로 줄이며 2 MiB를 넘으면 보내지 않습니다.

2. 미리보기와 가리기

아래 이미지가 전송할 내용입니다. 마우스나 터치로 영역을 끌면 검은 사각형으로 영구히 가립니다. 가리기를 되돌리려면 취소 후 새로 선택하세요.

키보드로 가릴 영역 지정 · 이미지 픽셀 기준

전송 중 취소하면 브라우저 작업은 중단됩니다. 이미 서버에 도착한 이미지는 회수되지 않을 수 있으므로 삭제가 필요하면 운영자에게 요청하세요. 링크는 다른 사람에게 전달하지 마세요.
